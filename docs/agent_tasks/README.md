# Agent 任务文档规则

本目录只管理已明确立项的 Agent 任务。

## 目录

- `pending/`：尚未完成验收的任务，包括待开始、进行中、阻塞和待复核状态。
- `completed/`：已经由协调者复核并明确验收通过的任务。

## 生命周期

1. 每轮新需求必须创建新的任务文档，不得覆盖或重新打开上一轮已完成任务。
2. 任务文档必须写明负责人、依赖、独占文件范围、禁止修改范围和验收条件。
3. 执行 Agent 完成后提交测试证据，但不能自行把任务标记为已验收。
4. Review 通过后，由负责 Git/文档整理的 Agent G 将任务文档移入 `completed/`。
5. 后续回归问题使用新的任务编号；旧文档只作为历史事实保留。

## 状态字段

任务文档顶部统一使用：

```text
状态：PENDING / IN_PROGRESS / BLOCKED / REVIEW / ACCEPTED
负责人：Agent X
依赖：任务编号或“无”
```

只有 Review 通过后才能使用 `ACCEPTED`。
