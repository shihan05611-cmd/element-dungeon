## 当前元素如何识别

不再使用独立元素卡片。当前元素由四组冗余信号共同表达：

1. 所有 HUD 面板统一的角部轮廓：水态为内收波阶，火态为外扬焰阶。
2. 框体微纹理：水态是低对比水平涟漪，火态是低对比上升火星。
3. HP/SP 面板与主动槽框左缘的同尺寸内嵌徽记：水滴菱形 / 分叉火苗。
4. 主动槽首格内的小字形与图标：水滴 + “水” / 火苗 + “火”。

即使去色观察，波阶 / 焰阶、水平 / 上升纹样、圆润水滴 / 尖锐火苗仍能区分状态；因此不只依赖蓝橙颜色。

## 像素边框 / 纹样拆解

- 目标是九宫格可实现的简约框体：角块建议 `16×16 px`，边块可沿单轴平铺，中块使用纯暗底叠加极低对比纹样。
- 公共结构：外侧 2 px 暗投影、1 px 结构边、1 px 内高光；禁止连续渐变和大面积发光。
- 水态角块：每 4 px 内收一级，角端使用成对短波阶；横边纹样只做稀疏 1 px 水平断线。
- 火态角块：每 4 px 外扬一级，角端使用不对称尖角火星；边纹样用稀疏 1 px 上升短阶。
- 内嵌元素徽记与外框相连，属于边框的一部分，不是独立卡片；其外接尺寸在两态保持一致。
