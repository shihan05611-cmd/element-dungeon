## 3. P2 启发式体验记录

本节是脚本化走查与界面启发式复核，不是玩家研究；主观观察没有写入战斗或成长规则。

- 固定/通用/无属性识别：实心圆“固定元素”、菱形“读取当前元素”、空心圆“无属性”均同时给出中文与元素英文；不看颜色仍可区分。初次扫视时策略行比技能说明更快被识别。
- 专属影响后续通用：接受成功显示“自动调谐 · ACTIVE_n → 当前元素”，随后 CurrentElement 与通用技能动态角标同步；失败只显示失败原因。当前正式目录没有可按键的专属主动，因此该表现用只读 CastSnapshot/正式策略语义夹具覆盖，原子切换由冻结的任务 14/15 回归覆盖。
- 手动切换频率：当前正式初始可按键技能只有通用 `element_bolt`；专项走查记录的一次通用释放前有 1 次手动切换（1/1 覆盖样本）。这是交互覆盖，不作为平衡结论；扩充正式主动内容后需重新采样。
- 已生成攻击锁定：接受反馈明确写出锁定元素；切换后已生成攻击仍按 CastSnapshot 展示，未观察到“投射物跟随实时元素”的误导。现有技能回归同时覆盖 buffered switch 后快照不变。
- 1/2/3 主动负担：1 个主动最易定位但选择少；2 个主动仍可单次扫视比较；3 个主动增加冷却/能量比较负担，但固定 1/2/3 键帽和不跳动卡片让操作路径保持稳定。没有因此增加技能栏。
- 0 主动流程：四个位置均为被动时警告清楚说明依赖普通攻击与被动，且警告本身不阻塞合法确认；任务 10/06 回归用四个不同被动定义验证可提交，并用普通攻击完成房间。当前正式六技能目录只有两个被动，截图为结构压力夹具并故意复用展示项；真实 RuntimeLoadout 会拒绝重复技能，因此不能把该截图误读为可提交的正式目录配装。
- 第三/第四元素：EARTH、WIND 模拟只改变元素文字/形状语义，HUD 与配装仍恰好四槽，没有新增分页、快捷栏或隐藏槽。
- 连续切换评审：当前正式内容没有形成连续两次以上专属切换的场景，未触发输入负担结论。待增加可按键专属主动后，只记录切换频率供后续输入评审，不修改共享四槽结构。
