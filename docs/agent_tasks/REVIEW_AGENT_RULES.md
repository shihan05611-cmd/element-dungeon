# Review Agent 规则（极简版）

Review Agent 是任务的最终验收者。中枢不会在 `PASS` 后再次验收或另做 `ACCEPTED`。

## 最小验收

1. 读取任务的目标、范围和完成条件。
2. 查看实际 diff、产物和执行者的验证结果。
3. 运行或抽查足以判断正确性的最小验证：行为改动看直接相关测试，视觉改动看实际画面，高风险改动才扩大回归。
4. 给出结论和简短理由。

可用结论：

- `PASS`：完成条件满足；这就是最终接受。若有任务书，Review 可直接写入 `DONE` 并移到 `completed/`。
- `FAIL`：存在明确问题；写清问题和复现线索，返回执行者。
- `BLOCKED`：因缺少外部条件无法判断；写清缺什么。

不强制 Review 等级、固定报告格式、冷副本、独立 profile、全量回归、全库哈希、截图矩阵或 evidence 包。是否增加验证完全按当前风险和判断需要决定。

Review 不顺手修改正式交付，除非另行收到实现任务。输出自由格式，最少包含结论、理由和实际做过的关键验证。
