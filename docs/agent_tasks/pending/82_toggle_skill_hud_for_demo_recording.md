# Demo 录制用技能 HUD 显隐按键

建议：gpt-5.6-terra / medium

Allowlist：战斗 HUD 的技能条可见性控制模块；项目输入映射；仅与显隐功能直接相关的 HUD 自动化测试、窗口渲染取证及 `docs/agent_tasks/evidence/task82/`。左上 HP/SP 状态区、Boss 栏、房间信息、交互提示、反馈层、配装/商店 Overlay、HUD 美术资源、技能输入与战斗逻辑均不得修改。本任务可在 Task 83 前独立执行，但不得与 Task 83 并发修改同一 HUD 模块；Task 83 后续清理状态栏时必须保留本任务的技能区显隐接口与行为。

目标：新增一个录制用快捷键，只隐藏或恢复主动技能条与被动技能条，不影响左上 HP/SP 状态区和任何游戏功能。

范围：新增输入动作 `toggle_skill_hud`，默认绑定当前未占用的物理键 `H`；CombatHUD 提供明确的设置/切换接口和当前可见状态，按键无回显、无提示横幅地原位切换 `SkillPanel` 与 `PassivePanel`。隐藏范围严格只有这两个技能区域；StatusPanel 的 HP、SP 始终显示，BossPanel、RoomTitle、FeedbackPanel、世界交互提示及 RunOverlay 维持原状态。隐藏仅影响绘制与鼠标命中，不暂停冷却刷新、不卸下技能、不屏蔽数字键/普攻/切形态输入，也不改变战斗、配装和流程；再次按键恢复时直接显示最新槽位、冷却与配装状态，不播放过渡动画。默认启动为显示，单次运行内跨房间保持用户选择，新 Run 或重新启动恢复默认显示。

完成：按 H 后主动、被动技能 HUD 同时完全消失，左上状态区及其中 HP/SP 逐像素保持，Boss 栏、房间文字与交互反馈不受影响；隐藏期间技能仍可正常施放、冷却继续推进、配装变化继续同步，恢复后显示实时结果。连续切换、按键 echo、商店/配装 Overlay 开关和跨房间均不产生错乱；新 Run/重新启动默认可见。提供同机位显隐前后窗口截图，并以自动化验证精确断言只有 `SkillPanel`、`PassivePanel` 的可见性发生变化以及隐藏期间的施法/冷却行为不变，相关 HUD 正式回归通过。
