# Task 93 分离式技能 HUD 概念重设计

建议：gpt-5.6-sol / high

Allowlist：`docs/agent_tasks/evidence/task93/` 内的概念图、局部特写、提示词与设计说明。现有代码、正式资源、测试以及 Task91/92 全部只读。

目标：在 Task92 视觉语言基础上重新设计分离式技能 HUD：主动技能位于底部中央，被动技能独立放在右下角。仅交付概念稿，不实装。

范围：

- 主动区：底部中央单独成框，横排 3 个较大槽位；保留键位 `1/2/3`、技能图标、`SP N`、冷却数字、禁用灰度与空槽的表达空间。
- 被动区：右下角单独成框，横排 4 个紧凑方形槽位，只承载图标与必要的冷却/禁用覆盖，不显示键位、SP 或文字说明。
- 两区必须明显分离，不得继续使用 Task92 的上下连体轮廓；同时使用一致的深蓝黑底、硬边像素结构、双层蓝色亮边和稀疏暗纹，使其仍属于同一套 HUD。
- 框体是固定的中性主题，不随水火元素切换，不加入水滴、火苗或其他元素徽记。
- 右下被动区须保留合理屏幕安全边距，不贴边，不遮挡主动区、角色主要活动区或其他 HUD；底部主动区保持视觉中心。
- Task92 概念只作为风格参考，不在原文件上覆盖；Task93 输出新文件，并在设计说明中明确 Task92 已被本版取代、但未删除历史稿。
- 按 `imagegen` 技能使用内置图像编辑流程。以 Task91 的 1920×1080 实机截图为 edit target，以 Task92 局部特写为 style reference；必须保持游戏场景、角色和左上状态 HUD 不变，只替换底部技能 HUD 区域并新增右下被动区。
- 若生成模型改变了场景像素，须用可追溯的无损合成恢复 edit target，仅保留主动区和被动区两个局部的变化。
- 严禁修改实现代码、正式资源和测试，严禁运行或声称完成实装。

完成：

- 输出一张 1920×1080 完整场景概念图、一张主动区最近邻放大特写和一张右下被动区最近邻放大特写；三者内容严格一致。
- 输出最终提示词和简短设计说明，明确两区的位置、尺寸层级、静态框体与未来动态内容区域。
- 人工确认：主动区准确 3 槽并在底部中央；被动区准确 4 槽并在右下角；两者无连接、无重叠、均有安全边距。
- 小尺寸下键位、图标、SP、冷却、禁用与空槽仍可辨认；被动区安静且不抢主动区层级。
- 独立 Review Agent 验证 evidence-only 边界、edit target 外像素保持、数量/位置/可读性后给出 PASS。
- 本任务仅构成概念设计，等待用户确认后另立实装任务。
