# Boss 元素立绘、被动特效与世界提示统一重绘

建议：gpt-5.6-sol / high

Allowlist：Boss 美术与动画资源模块；被动技能表现及其挂载适配模块；战斗预警表现模块；世界交互提示模块；与上述表现直接对应的测试、视觉取证和任务证据目录。玩家水/火形态美术只作只读参考；战斗数值、判定、Boss 状态机、房间流程与交互权威逻辑不在可变动范围内。

目标：以 Boss 默认形态为结构基准，重绘水、火两套元素形态并建立更强的流动感；把燃烧被动重绘为飘动火星，并让被动表现按 Boss 立绘的可视范围正确附着；统一近战预警和世界交互提示的像素化视觉语言，同时不改变任何玩法时序和功能。

范围：默认形态本体保持不变，水、火形态的 idle、walk、attack、cast、hurt、death 均从默认形态轮廓重新构造，帧数、朝向、动作语义和事件帧兼容现有动画；参考主角水/火形态塑造流动感的方法，但不得直接放大或复制主角效果，水形态需有连续流向，火形态可比主角更夸张，以轮廓连续的火焰、拖尾和火星表现能量，同时清除孤立亮点、贴图脏点和闪烁跳点。保留不息被动现有美术方向，只修正其与燃烧共同使用的挂载、缩放和锚点体系；燃烧改为围绕角色上升、飘散且有生命周期的火星，不再像固定火舌或地面火堆。被动特效尺寸以 AnimatedSprite2D 的实际可视包围、缩放和美术锚点为准，不以受击碰撞体直接决定，也不得重复乘算 Boss 的显示缩放；普通敌人与 Boss 上都要保持协调的相对覆盖范围。近战预警改为红色感叹号，复用现有感叹号轮廓而不起新标志，并与远程等其他预警保持颜色语义可分。所有世界交互提示统一为独立的像素键帽框包住“F”，紧接交互文案，彻底移除中点“·”；共用一套组件覆盖可交互、锁定、不可用和已消费等现有状态。所有新增/重绘贴图保持最近邻采样、像素网格与项目既有美术规范。

完成：Boss 默认、水、火三套形态在所有动作中轮廓稳定、元素流向连续，火形态明显更有张力且不再出现用户指出的孤立点；受击与死亡仍保持当前真实形态，不发生默认立绘回退。燃烧在静止与移动中均呈现自然飘动火星，不息观感不被重绘破坏；两种被动在普通敌人与 Boss 上跟随可视立绘而非碰撞体，缩放、脚底/躯干锚点和遮挡层级正确。Boss 近战窗口只显示红色感叹号且能按时清理；全部世界交互提示均显示“键帽 F + 文案”、无中点，原交互条件与单次提交逻辑不变。提供覆盖三形态各动作、两种被动在普通敌人与 Boss 上、近战预警和多种交互状态的窗口渲染对照图，并通过相关专项与正式回归。
