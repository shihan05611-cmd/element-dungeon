# HUD 水火双主题像素美术概念确认

建议：gpt-5.6-sol / high

Allowlist：`docs/agent_tasks/evidence/task79/` 下的概念图、对照图与设计说明。现有 HUD、元素状态接口、运行时代码、场景、正式美术资源、测试和其他任务证据全部只读，不得修改。

目标：在不进入实现阶段的前提下，为当前 HUD 产出可供用户确认的简约像素美术参考图；保持现有空间比例，取消独立元素枢纽，并把整个 HUD 设计成水、火两套状态主题。

范围：以当前 1920×1080 战斗 HUD 和用户截图为结构基线，保留已经确认的 HP/SP、主动槽、被动槽、Boss 信息和房间信息的空间占比与信息层级；概念图中彻底移除独立元素枢纽，不保留空洞占位。为同一套固定布局分别设计水态与火态两张完整 HUD 图，使用简约像素边框、九宫格可实现的面板纹理、低噪声暗色底和清晰高对比文字；HP、SP、冷却、危险等功能色保持语义稳定，水火差异主要落在框体、边角纹样、微弱底纹、状态字形或小型内嵌标记上，不能只依赖颜色，也不能因切换状态造成面板尺寸或内容跳动。允许同时给出至多两个视觉方向，但每个方向都必须成对提供水态/火态，不输出运行时资源，不修改工程。

完成：对应执行对话直接向用户展示至少一组同构的水态、火态完整 HUD 参考图，并附当前稿对照、色板、像素边框/纹样拆解和“元素枢纽消失后如何仍能识别当前元素”的简短说明；图中不存在独立元素卡片，整体空间比例与当前 HUD 一致，水火切换不改变布局，生命/能量/危险语义清楚。交付明确标注“仅概念，尚未实装”，等待用户选定或提出修改后才可另立实现任务。
