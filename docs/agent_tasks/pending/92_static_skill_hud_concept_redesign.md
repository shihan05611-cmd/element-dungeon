# Task 92 静态技能 HUD 概念重设计

建议：gpt-5.6-sol / high

Allowlist：`docs/agent_tasks/evidence/task92/` 内的概念图、局部特写、提示词与设计说明。现有代码、正式资源、测试及 Task91 证据全部只读。

目标：重新设计一套用户可确认的底部技能 HUD 概念图。它是固定的中性主题，不随水/火元素切换，并与 Task91 新状态 HUD 的像素美术语言一致。

范围：

- 只设计底部中央技能 HUD：上排 4 个被动槽、下排 3 个主动槽；结构以当前 `scripts/combat_hud.gd` 和 Task91 最新实机截图为准。
- 视觉方向锁定为深蓝黑底、硬边像素构造、粗细有层次的双层亮边、少量稀疏暗纹；与 Task91 状态栏协调，但不得加入水滴、火苗或会暗示元素切换的主题徽记。
- 被动区更轻、更薄，只承载 4 个纯图标；主动区更厚重，清晰承载图标、左上键位 `1/2/3` 与底部 `SP N`。空槽仍能明确辨认。
- 静态仅指框体与装饰不切换；概念必须给动态内容留出清晰空间，包括技能图标、键位、SP 消耗、冷却遮罩、禁用灰度和空槽。
- 取消旧稿中上下两块彼此松散、像调试框的感觉，设计为一个视觉上统一、轮廓紧凑的底部组件；被动与主动仍需一眼分层。
- 不改变场景、角色、状态 HUD、Boss HUD、房间文字或任何游戏内容。概念阶段严禁修改实现代码和正式资源。
- 按 `imagegen` 技能使用内置图像生成/编辑流程；以 Task91 最新 1920×1080 实机图为结构参考。生成时要求场景与其他 HUD 不变，只重设计底部技能 HUD。必要时先生成 HUD 局部，再无损合成到实机截图，避免模型重画游戏画面。

完成：

- 输出一张 1920×1080 同场景完整概念图和一张无插值放大的技能 HUD 局部特写；两者中的 HUD 必须一致。
- 输出简短设计说明，明确主动/被动层级、固定装饰、动态内容区域，以及为何不需要水火双版本。
- 保存最终提示词，注明使用的参考图角色和内置 imagegen 工作流。
- 人工确认：3 个主动槽与 4 个被动槽数量正确，布局位于底部中央；小尺寸下键位、图标、SP 信息可读；整体与 Task91 状态栏协调，但不是旧 Task79 作废稿的复刻。
- 本任务仅交付概念设计，等待用户确认后才能另立实装任务。
