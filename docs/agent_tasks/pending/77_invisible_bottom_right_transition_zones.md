# 无立绘的房间右下角传送交互区

目标：取消传送门立绘，以房间右下角可行走区域作为原传送功能的交互区，并保持原有流程逻辑不变。

范围：覆盖普通战斗房间的路线传送和商店离开传送；移除锁定态与激活态传送门图像，仅保留必要交互提示；将以传送门坐标和距离为依据的交互判断改为各房间本地坐标下可配置的右下角矩形区域，不改宝箱解锁、商店离开、房间切换及流程权威逻辑。

完成：所有适用房间均不再显示传送门立绘；玩家位于右下角交互区内时可看到正确提示并按原按键触发，区域外不能误触；普通战斗房间仍需清场并开启宝箱后才能传送，商店仍可正常离开，每次交互只提交一次且能进入原本的下一流程；相关测试不再依赖传送门世界坐标，并覆盖区域内外、锁定、解锁和消费状态。
