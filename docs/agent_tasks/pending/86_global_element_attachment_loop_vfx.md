# 元素附着循环特效全局化

建议：`gpt-5.6-terra` / `medium`

Allowlist：`SkillVfxCoordinator` 中敌方元素附着循环表现的判定、创建、同步与清理模块；既有燃烧/不息表现 Scene、SpriteFrames 和贴图只读复用；与元素附着循环、被动触发隔离及房间生命周期直接相关的自动化测试、窗口取证和 `docs/agent_tasks/evidence/task86/`。燃烧/不息的被动定义、数值、tick/普攻触发条件、元素结算、伤害与配装注册逻辑均不得修改；不得新增或重绘 VFX、图标及其他美术资源。

目标：火元素附着时始终显示现有燃烧循环特效，水元素附着时始终显示现有不息循环特效，不再要求玩家装备对应被动；被动原本的伤害、持续刷新或普攻触发等 gameplay 效果仍只在实际装备该被动时生效。

范围：敌人进入当前战斗观察集合后，循环表现只由其权威 `ElementCarrier` 快照决定：`fire_amount > 0` 唯一生成一份 burning loop，`water_amount > 0` 唯一生成一份 unending loop；层数在正数之间变化不得重复创建，降为零立即清理，再次附着重新创建。两种元素同时为正时允许两份循环共存，不用被动注册状态筛掉其中之一。装备、卸下或替换燃烧/不息被动不应创建、销毁或重启已经由元素附着维持的循环。现有 burning tick 与 unending trigger 强调动画继续只响应对应被动的真实已接受结算：没有被动时即使存在元素循环，也不得产生 tick 伤害、普攻触发、触发计数或对应爆发动画。敌人死亡、退出观察、换房、玩家死亡和 Coordinator teardown 必须清除全部实例及 WeakRef，不跨房间残留；继续沿用现有 Boss/普通敌人视觉体积适配和 reduced-motion 语义。

需迁移断言：技能 VFX 正式专项中“未注册被动时没有循环”的断言改为未注册但有火/水附着时分别存在唯一循环；燃烧/不息注册专项拆分验证“循环由元素层决定、tick/trigger 由被动注册和真实结算决定”。补充无被动时多次增层不重复、降零清理、重新附着、双元素共存、装备/卸下不重建、无 gameplay 触发以及死亡/换房清理；不得放宽被动伤害、触发次数和元素权威层数断言。

完成：未装备任何被动时，给敌人附着火或水即可在真实窗口看到对应既有循环，清空元素后立即消失；装备燃烧/不息只增加原本对应的 gameplay 与触发爆发，不改变循环的出现条件。普通敌人和 Boss 均无重复实例、比例漂移或跨房残留；提供无被动火附着、无被动水附着、双元素、清零以及装备前后同机位证据，专项与相关正式回归通过，且工作区没有新增 VFX 美术文件。
