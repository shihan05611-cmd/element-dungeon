# 元素反应特效击退跟随

建议：`gpt-5.6-sol` / `high`

Allowlist：`CombatFeedback` 的反应组合定位分支；Task87 反应组合的承载脚本/Scene；与命中点跟随、目标释放和生命周期直接相关的自动化测试、窗口取证及 `docs/agent_tasks/evidence/task90/`。不得修改伤害、元素反应、击退、受击、死亡等 gameplay，`CombatResult`/`HitRequest` 契约，Task87 已确认的双色动画、固定“反应”文字、强度档位、时长、并发与去重，伤害数字轨迹，HUD、Boss 附着特效、Task88、RunOverlay、商店、Cloud 或其他未提交并行改动；不得新增或重绘 VFX 位图。

目标：普通怪物在反应触发后被击退时，0.42 秒反应组合不再留在旧世界坐标，而是持续对齐该目标身上的原始局部命中点；静止目标和 Boss 的现有观感保持不变。

范围：`CombatFeedback` 已持有本次 `receiver`，生成反应组合时从其有效 `Node2D` 宿主计算 `local_hit_offset = target.to_local(result.hit_position)`，反应节点仍归 `CombatFeedback` 管理，通过弱引用在生命周期内将世界位置同步为 `target.to_global(local_hit_offset)`，不得把表现节点直接交给目标所有而导致死亡时提前释放。目标失效、离树或被释放时，立即停止跟随并冻结在最后一个有效世界位置，随后按原 0.42 秒动画正常结束；无法取得有效宿主时回退为 Task87 的固定 `hit_position`。最终伤害数字与固定“反应”飘字继续从原命中点独立上浮，不跟随怪物；减少动态只禁止自身位移/旋转动画，但仍需保持目标锚定。不得延迟表现生成或修改信号顺序来规避错位。

完成：真实窗口连续帧证据中，易击退普通怪物在反应生成、击退中段和动画末段的反应组合均贴合相同身体局部位置，没有留在原地或瞬移；伤害数字仍停留在原命中区域。静止普通怪、Boss、左右击退、多目标同时击退、减少动态与目标中途死亡/离树均正确；目标释放后特效冻结并按时清理，无悬挂引用、跨房残留或并发上限回归。专项锁定局部偏移、逐帧跟随、失效回退、原 0.42 秒生命周期、16 并发与既有去重键，Task87 及相关正式回归通过。独立 Review 至少检查一次真实窗口的击退连续帧对照。
