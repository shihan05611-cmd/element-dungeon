建议：`gpt-5.6-terra` / `medium`

Allowlist：宝箱交互物的场景表现；引燃内容定义、等级成长、执行快照与状态结算链路；与本任务直接相关的商店/成长、引燃、世界提示自动化测试、窗口取证及 `docs/agent_tasks/evidence/task88/`。不得修改宝箱领取与奖励逻辑、其他交互物表现、技能 HUD、`RunOverlay`、Task87 的 `CombatFeedback`/反应视觉、Cloud L 配置槽或其他现有未提交并行改动；不得新增或重绘美术素材。

目标：将宝箱上方交互提示从当前 12px 稍微放大到 14px，并为当前无法升级的引燃补齐可在既有商店升级页正常购买等级的三级成长曲线。

范围：宝箱 `Prompt` 仅调整字号及为避免裁切所需的最小标签边界，保留现有像素字体、颜色、描边、文案、F 键格式、浮动节奏和位置；传送区域、皇冠等其他世界提示仍为 12px。引燃保持初始拥有、ACTIVE_2、火形态限定、零 SP、8 秒持续与 8 秒冷却、普攻 1 层火附着、1.5 倍气流/既有命中范围及无层数上限不变。成长固定为 Lv1 每吸收 1 层火使普攻增伤 5%；Lv2 每层 6%，升级价 60 梦尘；Lv3 每层 7%，升级价 100 梦尘。复用既有 `ActiveSkillProgressionDefinition`，建议以等级 `damage_scale = 1.0 / 1.2 / 1.4` 表示对每层 5% 增量的缩放，最终倍率严格为 `1 + 吸收层数 × 0.05 × damage_scale`，不得把总倍率或基础攻击再次整体乘算。已接受的引燃释放必须冻结当次等级效果，后续升级/重置只影响下一次释放；既有商店升级、最高级阻止、支出与 70% 重置退款权威链路直接复用。

完成：真实窗口中宝箱提示明显比其余交互提示略大、无裁切遮挡且浮动不漂移；对应断言改为宝箱 14px、其他提示 12px。商店升级页可将引燃从 Lv1 升至 Lv2/Lv3，分别正确扣除 60/100 梦尘，Lv3 禁止继续升级，重置沿既有规则退款并回到 Lv1。专项锁定 1/5/20 层在三级下的倍率、已接受释放快照、升级/重置、持续时间/范围/附着不变及引燃仍不进入购买和奖励池；相关正式回归通过。Review 使用 `gpt-5.6-terra` / `low` 做轻量独立核验，重点检查数值公式、Allowlist 与一张真实窗口宝箱对比证据。
