# Boss 与普攻表现清理

目标：清理 Boss 头顶异常表现及受击时的原版立绘回退，并将普攻序列帧中的“气流”拆成可独立控制的表现层，同时保持现有战斗表现与玩法节奏。

范围：排查 Boss 头顶“三个点”等异常表现的真实来源，修正攻击预警的显示与清理；修正 Boss 普通受击、破韧和死亡边界下的形态动画选择，非真正中性形态不得回退原版立绘；将普通、水、火三套普攻中的气流从角色序列帧分离为独立资源与节点，不改变角色主体帧、朝向、判定、伤害和施放时序。

完成：Boss 不再出现常驻、重叠或无法解释的头顶“三个点”，近战、远程和召唤预警仍能在正确窗口出现并及时清理；普通命中和破韧期间始终保持当前形态外观，只有形态机制真正进入中性形态时才显示中性立绘；三种普攻的主体与气流已物理分层、可分别开关，默认合成播放与改动前逐帧观感一致，且普攻战斗逻辑回归通过。
