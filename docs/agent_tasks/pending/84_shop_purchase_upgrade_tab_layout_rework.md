# 商店购买/升级切换与布局精简

建议：`gpt-5.6-terra` / `medium`

Allowlist：

- `scripts/ui/run_overlay_interface.gd` 的正式商店 Overlay 构建与本地视图状态
- `scripts/ui/combat_ui_tokens.gd` 中商店直接使用的间距/样式 token；不得改变无关 HUD 语义色
- `resources/content/skills/` 下三份正式被动技能内容资源
- 与商店布局、Tab、长描述和正式技能内容直接相关的 `combat/tests/` 测试/截图 runner，以及 `docs/agent_tasks/evidence/task84/`
- 本任务书

目标：不使用新贴图，仅用现有代码式面板、图标、字体和颜色改善商店布局；加入购买/升级双 Tab，妥善承载长技能描述，并删去不必要的常驻账务文案。

范围：

- 商店候选区增加“购买 / 升级”双 Tab。切换只改变本地视图，不提交事务、不替换 `ShopDraft`、不改变钱包、技能等级、重置、配装或离店权威逻辑。
- “购买”页只列未拥有的主动与被动技能并提供购买操作；购买成功后该技能从购买页消失并可在升级页/已拥有区按既有规则出现。
- “升级”页只列已拥有的主动技能；显示当前等级、下一等级效果、升级价格和升级/重置按钮。满级技能仍可见但升级禁用。被动技能无等级，不进入升级列表。
- Tab 状态在同一商店会话的购买、升级、重置、配装和 snapshot 刷新后保持；首次打开默认“购买”。支持鼠标与既有键盘/手柄焦点导航，并有清楚的选中/悬停/禁用状态。
- 候选卡仅保留图标、名称、主动/被动、拥有/等级、核心数值与操作；完整描述移到独立的“当前选中技能详情”区域。详情正文正常换行，超长时只让详情区滚动，不缩小字号、不撑高单张卡、不遮挡按钮；至少覆盖 80 个中文字符压力用例。
- 保留右侧即时配装的 A1–A3 / P1–P4、选择、拖拽、清槽和类型限制；通过间距、对齐、留白与现有金/青/紫层级降低嵌套框和后台表单感，不新增任何 PNG/SVG/Theme 贴图。
- 三份正式被动技能描述删除字面前缀“严格被动槽：”，保留实际效果、限制与数值。测试不得再要求描述包含这五个字；槽位类型安全改由既有 gameplay 类型、RuntimeLoadout 规则和内容字段的语义断言覆盖，不改变主动/被动槽兼容规则。
- 已拥有主动技能的升级卡删除常驻的“累计实付 ✦ … · 预计返还 ✦ …”整行。用户主动点击“重置”后的确认区仍显示本次实际返还额；结算、结果页与经济统计保持不变。

完成：

- 购买/升级两页过滤、切换、刷新保持和空列表状态正确；所有既有购买、升级、重置、配装、关闭与物理离店行为不变。
- 商店主视图不再出现“累计实付”或“预计返还”，三份被动描述不再出现“严格被动槽”；重置确认仍能显示权威返还额。
- `1920×1080`、`1366×768`、`2560×1440` 下无溢出、重叠或按钮被挤出；提供购买页、升级页、长描述、满级/禁用和四被动配装的真实窗口截图。
- 自动化覆盖 Tab 本地性与持久性、页面过滤、长描述布局、文案删除、被动语义约束以及既有事务不回退；相关正式回归通过。
- 改动集中在 Allowlist，且 `assets/ui/shop/` 或其他新贴图目录没有新增运行资产。
