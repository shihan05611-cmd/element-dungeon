# 商店购买/升级切换与当前配装呈现

建议：`gpt-5.6-terra` / `medium`

Allowlist：

- `scripts/ui/run_overlay_interface.gd` 的正式商店 Overlay 构建与本地 Tab 状态
- `resources/content/skills/` 下三份正式被动技能内容资源
- 与商店 Tab、卡片过滤、当前配装槽和正式技能内容直接相关的 `combat/tests/` 测试/截图 runner，以及 `docs/agent_tasks/evidence/task84/`
- 本任务书

目标：保留当前商店已经成立的两列结构、卡片内容和操作逻辑，只把混排的购买与升级拆成两个 Tab，并把右侧当前配装改成清楚的三主动槽、四被动槽两排展示。

范围：

- 商店主体继续使用现有两列：左列技能候选，右列当前配装。两列宽度、现有滚动区、卡片尺寸、技能描述位置、按钮布局和顶部/底部区域均不得因本任务重新设计；不得增加第三列、独立技能详情区或新的信息架构。
- 只在左列现有候选区顶部增加“购买 / 升级”双 Tab。切换只改变本地列表过滤，不提交事务、不替换 `ShopDraft`，不改变钱包、技能等级、重置、配装、关闭或物理离店逻辑。
- “购买”页等于现有候选列表去掉所有已拥有技能：只显示未拥有的主动与被动技能，并完整复用当前未拥有卡片的图标、名称、类型、描述、价格和购买按钮；除增加 Tab 与过滤外，购买页无其他视觉或内容变化。
- “升级”页等于从现有混合列表提取已拥有且可显示等级的主动技能，并完整复用当前已拥有主动卡片的等级、当前/下一级效果、升级价格、升级与重置操作。满级主动技能仍显示但升级禁用；无等级被动不进入升级页。
- 首次打开商店默认“购买”；同一商店会话中，购买、升级、重置、配装和 snapshot 刷新后保持当前 Tab。购买成功后该技能从购买页消失；若为主动技能，可在升级页出现。
- 右侧保留当前已拥有技能选择、点击/拖拽配装、清槽和主动/被动类型限制，只重做“当前配装”的槽位呈现结构：
  - 主动技能一行，横向均分展示 A1–A3 三个槽；
  - 被动技能一行，横向均分展示 P1–P4 四个槽；
  - 已装备槽显示槽位编号、技能图标、技能名称和权威 `Lv.N`；等级读取现有技能进度，不建立新的等级来源；
  - 当前无升级被动显示其权威固定等级（现状通常为 `Lv.1`），但不因此进入升级页、获得升级按钮或改变被动无升级规则；
  - 空槽只保留槽位编号与空白槽面，不显示“空槽”二字，也不显示虚假图标、名称或等级；
  - 保留现有选中态、禁用态、拖拽、点击和清槽行为，不使用新贴图。
- 三份正式被动技能描述删除字面前缀“严格被动槽：”，保留实际效果、限制与数值。测试不得再要求描述包含这五个字；槽位类型安全继续由 gameplay 类型、RuntimeLoadout 规则和内容字段的语义断言覆盖，不改变兼容规则。
- 已拥有主动技能的升级卡删除常驻的“累计实付 ✦ … · 预计返还 ✦ …”整行。用户主动点击“重置”后的确认区仍显示本次权威返还额；结算、结果页和经济统计保持不变。
- 不新增或消费任何商店 PNG/SVG/Theme 贴图，不改字体、全局主题、技能数值、价格、等级上限、被动升级规则或配装容量。

完成：

- 购买页与任务前现有未拥有卡片逐项一致，只少了已拥有/升级卡；升级页只承接任务前现有的已拥有主动卡，两个页面没有重新排版或新增详情区。
- Tab 切换、会话内保持、购买后迁移、空列表和焦点导航正确；所有既有购买、升级、重置、配装、关闭与物理离店事务不回退。
- 当前配装严格为 A1–A3 一行、P1–P4 一行；已装备技能显示图标、名称和权威等级；全部空槽均不出现“空槽”文字，且两排在 `1366×768`、`1920×1080`、`2560×1440` 下不溢出、不重叠。
- 商店主视图不再出现“累计实付”或“预计返还”，三份被动描述不再出现“严格被动槽”；重置确认仍显示实际返还额，被动仍不可升级。
- 提供同一会话的购买页、升级页、三主动/四被动满配、主动/被动混合空槽和长描述压力截图；视觉对比证明除 Tab 分流与当前配装槽呈现外，现有两列商店没有被重新设计。
- 自动化覆盖列表过滤、Tab 本地性与持久性、配装槽图标/名称/等级、空槽无文案、被动无升级、文案删除以及既有事务不回退；相关正式回归通过。
