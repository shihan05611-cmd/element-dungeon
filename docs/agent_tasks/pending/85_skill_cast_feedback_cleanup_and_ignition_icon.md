# 技能释放提示精简与引燃图标

建议：`gpt-5.6-sol` / `high`

Allowlist：战斗 HUD 中技能释放尝试的玩家可见反馈投影；玩家引燃普攻已分离气流层的固定 `1.5×` 缩放、颜色与复原表现；引燃固定普攻快照中的近战查询倍率及其由视觉边界反推的配置；引燃内容资源的图标绑定；`assets/generated/vfx/ignition/` 下本任务新增的正式图标；与技能释放提示、引燃命中/特效边界、内容图标和真实 HUD 显示直接相关的自动化测试、窗口取证及 `docs/agent_tasks/evidence/task85/`。其他技能执行、元素切换、冷却、SP、伤害与普通普攻查询只读；L 键配置槽、RunOverlay、商店 Overlay、输入映射、其他技能图标、Boss/交互提示及 Cloud 并行任务涉及模块均不得修改。调度前必须确认 Task 81、83 已无执行者写入相同模块；若仍在执行或 Review，Task 85 顺序等待其收口，不得并发覆盖。

目标：彻底取消技能释放成功、技能自动切换元素以及技能释放失败产生的玩家可见提示，为引燃补齐正式像素风技能图标，并修正引燃普攻等比放大后特效前缘与真实命中边界间隔过大的问题；不改变任何技能结果、元素状态或其他反馈系统。

范围：删除 `CombatHUD` 对技能 `cast_attempted` 的成功/失败提示投影，包括自动调谐、固定/当前/无属性锁定文案，能量不足、冷却中、忙碌、被动不可释放、空槽与通用释放失败文案，以及由这些结果产生的槽位“锁定/失败”瞬时文字；清理仅服务于该投影的 `_pending_auto_change`、接受文案/语气和拒绝文案辅助分支。保留结构化 `CastAttemptResult`、技能执行失败语义、冷却/SP 扣除规则和调试可观测性；失败仍不得提交技能事务，成功的专属技能仍按既有规则自动切形态。技能图标的灰度禁用、冷却遮罩/秒数和 SP 状态视觉属于常驻状态，不得删除。`FeedbackPanel` 仍服务于手动切形态及其失败/排队、色觉/减少动态、元素反应/同元素减伤、配装提交和 Overlay 错误，因此不得整体删除；世界 F 指引、Boss 预警和伤害飘字不属于本任务。

引燃图标新增为 `256×256` 透明 PNG，沿用现有正式主动技能图标的像素风、有限色阶、硬边缘与无文字原则；画面语义为数枚火星向中心汇聚，形成明亮橙色引燃核心，突出“吸收火元素后强化自身”，不得画成普通火球、爆炸或持续燃烧被动。图标在 `32×32` HUD 实际显示尺寸仍须一眼可辨，橙/金核心与深红轮廓层级清楚；仅绑定到 `ignition` 内容资源，不新增世界 Delivery、持续特效或玩法资源。通用 HUD 读取该图标即可，不得为此修改 L 键配置槽或商店代码；H 键隐藏技能 HUD 时图标随 `SkillPanel` 正常消失，恢复后显示最新状态。

引燃 `BasicAttackAirflow` 的视觉倍率固定为普通普攻的 `1.5×`，保持现有中心、逐帧贴图与左右翻转规则，不再通过额外放大或前移特效追赶命中范围；橙色要求保持。以普通普攻关键命中帧测量特效最前方非透明像素到普通真实查询前缘的既有舒适宽容量 `P`，再测得固定 `1.5×` 引燃特效的最前方像素位置 `V1`，按 `引燃查询前缘 = V1 + P` 反推新的实际命中距离和快照查询倍率。该倍率应作为有注释、有公式来源的确定配置在施放接受时锁定，不得在每次攻击时运行时扫描贴图，也不得继续写死为 `1.5`；普通普攻的特效、查询范围和宽容量完全不变。反推使用实际攻击可见/命中关键帧并覆盖左右朝向，查询前缘只能保留原固定余量，不能明显落在特效后方或把余量再次按倍率放大；动画结束、引燃清除、受击/死亡或切回普通攻击后，气流的基础 scale、position、modulate 均无残留恢复。

需迁移断言：HUD 配装反馈专项中“结构化释放失败产生不同文案”和“技能成功锁定/自动调谐文案”改为成功、失败均不改变玩家可见反馈面板，且手动切形态反馈仍存在；Task 24、Task 40 中 busy 拒绝产生反馈的断言改为无 FeedbackPanel/无槽位瞬时文字，同时保留灰度禁用、冷却遮罩与权威拒绝结果。内容目录中 `ignition.icon == null` 的断言改为图标存在且路径稳定，并把引燃加入正式图标路径/透明度/尺寸检查。Task 81 继续强断言气流 scale 恰好 `1.5×`，但把 `melee_query_multiplier == 1.5` 与固定距离样例改为反推公式断言：引燃真实前缘等于 `1.5×` 特效前缘加普通固定余量、左右镜像一致、边界内可命中/边界外不可命中、接受后范围快照稳定且退出状态完整复原；不得删除其他非技能反馈与玩法层的拒绝原因断言。

完成：普通技能成功、专属技能自动切形态成功以及能量不足、冷却、忙碌、不可释放和空槽失败均不显示反馈横幅或槽位瞬时文字，但结果、状态切换、冷却/SP、灰度与冷却遮罩完全正确；手动切形态、辅助模式、反应/减伤及 Overlay 错误反馈仍正常。引燃内容持有唯一正式图标，原尺寸透明背景无脏边，实际 HUD 中与现有图标风格一致并在正常、禁用灰度、冷却和 H 键显隐状态下正确显示。引燃特效严格为普通气流的 `1.5×`，实际命中前缘由该特效前缘加普通固定余量反推，左右朝向一致、边界外目标不受击，玩家本体和状态结束后的普通攻击无视觉漂移；提供普通/引燃同机位、命中边界叠加诊断、反推公式记录和原图证据。专项与相关正式回归通过，`scripts/ui/run_overlay_interface.gd`、L 键配置槽及 Cloud 并行改动没有被触碰。
