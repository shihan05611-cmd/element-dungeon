# Task 94 技能 HUD 层级与状态概念重设计

建议：gpt-5.6-sol / high

Allowlist：`docs/agent_tasks/evidence/task94/` 内的概念图、状态展示、局部特写、提示词与设计说明。代码、正式资源、测试及 Task91–93 全部只读。

目标：在 Task93 分离布局基础上制作新的技能 HUD 概念版本，重新定义主动/被动的视觉层级、主动冷却表达以及右下 `4×1` 被动状态。仅交付概念稿，不实装。

范围：

- 主动技能区仍位于底部中央，横排 3 槽，但整体比 Task93 更矮、更厚重、更紧凑；只保留统一厚外框、槽间分隔与角部键位片，移除每个槽位重复的内层长方形描边。
- 每个主动槽左上角使用嵌入轮廓的角部键位片，显示 `1/2/3`；`SP N` 固定在槽内右下角，避免与图标和冷却读秒竞争。
- 主动冷却采用竖向、自下而上的擦除表现，读秒始终居中。概念中至少同时展示：一个正常槽、一个处于冷却且显示居中读秒的槽、一个完全空白且无任何图标/符号/占位标记的空槽。
- 被动技能区采用右下角 `4×1` 紧凑横排，锚定屏幕右下并向左生长；右下安全边距固定，不随已解锁数量向屏幕外扩张。
- 被动槽不得显示键位数字、SP 或文字。使用与主动框同源的内高光与暗外沿，但线宽更细、亮度更低、轮廓层次显著更弱，不能与主动区争夺视觉层级。
- 被动状态必须清楚定义并展示三类：空槽为内凹虚线轮廓；未解锁槽使用小锁图标；已装备/可响应槽可使用细亮边脉冲。脉冲只表现为轻微边缘亮度变化，不放大、不闪白、不增加元素徽记。
- 框体继续使用固定中性蓝黑像素主题，不随水火切换。Task93 仅作布局和材质参考，本任务不得覆盖旧证据文件。
- 按 `imagegen` 技能使用内置图像编辑流程。以 Task91 的 1920×1080 实机截图为 edit target，Task93 为 style reference；保持游戏场景、角色、左上状态 HUD 及其他像素不变，只修改底部主动区和右下被动区。
- 如模型改变 edit target 外内容，须以无损合成恢复，确保变化严格限制在两块 HUD 区域。
- 严禁修改实现代码、正式资源和测试，严禁运行或声称完成实装。

完成：

- 输出一张 1920×1080 完整场景概念图、一张主动区最近邻放大特写、一张被动 `4×1` 最近邻放大特写，以及一张状态规则展示图。
- 完整图与两张特写对应像素一致；状态规则图可单独放大解释，但不得引入完整图中不存在的框体风格。
- 主动区人工确认：更矮重、3 槽、统一厚外框、无重复内层长方形描边、仅有槽间分隔与角部键位片；SP 右下、冷却自下而上擦除、读秒居中、空槽无标记。
- 被动区人工确认：右下 `4×1`、向左生长、无键位数字；内凹虚线空槽、小锁、细亮边脉冲三态均可辨认，且视觉层级显著弱于主动区。
- 保存最终提示词和设计说明，明确静态框体、动态覆盖层、锚点与状态规则；注明使用内置 imagegen 工作流及各参考图角色。
- 独立 Review Agent 验证 evidence-only 边界、edit target 外像素一致性、状态与层级要求后给出 PASS。
- 本任务只构成新的概念版本；Task92/93 不删除，但由 Task94 取代为待确认候选。用户确认后才能另立实装任务。
