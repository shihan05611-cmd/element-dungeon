# 元素切换提示清理与 Boss 附着特效适配

建议：`gpt-5.6-terra` / `medium`

Allowlist：`CombatHUD` 中元素切换事件到顶部 `FeedbackPanel` 的投影分支；燃烧/不息常驻与触发特效的协调、承载节点及 Boss 专用视觉锚点；与本任务直接相关的 HUD/VFX 自动化测试、窗口取证及 `docs/agent_tasks/evidence/task89/`。不得修改元素切换判定与输入、技能释放、元素附着/被动 gameplay、Boss 立绘/碰撞/受击体/AI、Task87 元素反应表现与跟随方式、RunOverlay、商店、Cloud 并行模块或任何现有未提交无关改动；不得新增、重绘或生成人物、粒子、图标等位图素材。

目标：元素切换不再显示文字加框的顶部提示；燃烧与不息的附着循环及被动触发特效在 Boss 身上按 Boss 立绘体量放大和重新锚定，普通敌人的现有表现不变。

范围：手动成功切换、自动切换、排队切换和切换失败均不得创建、显示或替换顶部 `FeedbackPanel` 文案；元素图标、颜色、技能可用状态、调试语义及真实切换结果照常刷新，其他错误、同元素减伤、设置变化等既有 `FeedbackPanel` 用途保持不变。Boss 适配优先使用只服务表现的 `ElementAttachmentAnchor` 一类场景锚点或等价视觉配置，由 Boss 立绘可见体量决定位置和缩放，不从碰撞体反推，也不改变 Boss 根节点或立绘缩放；燃烧/不息的 Loop 与 Trigger 必须继承同一 Boss 适配，双色同时存在时中心、比例一致。普通敌人继续使用现有锚点、比例、动画、生命周期与被动触发条件；不得复制或修改既有 SpriteFrames。

完成：真实窗口中连续手动切换、技能自动切换、排队及失败切换均没有文字框提示，但元素状态与技能可用性正确变化，其他 HUD 反馈回归不受影响。Boss 火、水、双元素以及燃烧/不息 Trigger 的同机位截图中，特效覆盖 Boss 主体而不再缩成脚边小点，不遮住主体辨识且清除元素后立即消失；普通敌人火、水、双元素对照与当前尺寸/位置一致。定向断言锁定元素切换不投影 `FeedbackPanel`、Boss 双特效共用视觉适配、普通敌人不被放大、清理/去重/被动触发契约不变；相关回归通过。Review 使用 `gpt-5.6-terra` / `low` 做轻量独立核验，并以真实窗口 Boss/普通敌人对照为主要视觉证据。
