目标：把左上角水/火状态 HUD 改为直接从 Task79 已确认的局部概念图扣取的固定尺寸贴图，忠实保留概念稿的双层像素边框、右侧水滴/火苗断口、稀疏暗纹和整体比例。

范围：

- 水、火源图分别使用 `docs/agent_tasks/evidence/task79/status_hud_water_scoped_concept.png` 与 `status_hud_fire_scoped_concept.png`。
- 只扣左上状态条。保留概念图中的 `HP`、`SP` 标签；清除写死的数值和填充内容，让 HP/SP 数值与红蓝填充继续由现有运行时状态驱动。

- 不改技能槽、被动槽、Boss HUD、房间文字、RunOverlay、战斗逻辑和任何非状态 HUD。
- 必须保留当前低血量提示、实时数值刷新、血条/能量条填充和现有可访问性行为；若贴图已包含 HP/SP 标签，关闭原代码标签的可见绘制，避免重影，但保持稳定节点契约。
