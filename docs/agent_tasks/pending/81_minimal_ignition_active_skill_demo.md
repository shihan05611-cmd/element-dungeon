# 极简引燃主动技能 Demo

建议：gpt-5.6-terra / high

Allowlist：战斗执行、可见战场目标查询与元素原子消耗模块；玩家引燃状态、固定普攻快照、引燃专用近战范围与生命周期模块；技能内容目录及本任务新增的 gameplay/content 资源；现有元素回收表现和已分离普攻气流层的接入代码；与本技能直接相关的战斗、内容目录、窗口渲染测试及 `docs/agent_tasks/evidence/task81/`。现有元素回收粒子贴图、普攻贴图只读复用；成长升级、奖励池、商店经济、房间流程、敌人逻辑、其他技能、正式新图标与新 VFX 素材不在可变动范围内。Task 78 涉及的 VFX 基线若尚未收口，本任务不得与其并发修改同一表现协调模块。

目标：以最小可展示实现新增火系主动技能“引燃”：吸收可见战场内所有已激活存活敌人的全部火元素，使玩家进入 8 秒引燃状态；每吸收 1 层火使普攻伤害提高 5%，引燃期间普攻固定附着 1 层火元素、实际攻击范围扩大 50%，独立普攻特效同步放大 50% 并变为明显橙色。

范围：新增固定火语义的主动技能 `ignition`，施放时自动切换/锁定火形态，0 SP 消耗、8 秒冷却、无攻击 Delivery；没有可吸收火层时在提交前失败，不开始冷却、不改变敌人或玩家状态。复用现有可见战场查询、稳定目标排序和 `ElementCarrier.prepare_consume_all(FIRE)`，但不得沿用元素回收“恢复 SP / 满 SP 拒绝”的业务条件；一次原子事务锁定各目标火层、汇总 `N`、清空火层并激活引燃，水层不变。引燃倍率固定为 `1.0 + 0.05 × N` 且不设额外层数上限；状态持续 8 秒，重复激活以新 `N` 覆盖旧倍率并刷新时间，死亡、换房、重载和新 Run 必须清除。只在固定普攻接受时锁定该倍率、固定 `FIRE`、附着量 1 与 `1.5×` 近战查询范围；攻击接受后即使引燃在命中帧前结束，也保留该次快照的伤害、元素和范围。范围扩大必须作用于真实命中查询，并与左右朝向一致；不得仅放大画面，也不得改变非引燃普攻、其他主动技能、被动、遗物和既有在途攻击，不得运行时修改共享 `SkillDefinition` 资源。表现仅复用现有元素回收的火元素抽取/到达粒子，并在引燃普攻时复用现有 `fire_attack` 动画、火命中反馈和已分离 `BasicAttackAirflow`：只将独立气流特效相对原尺寸放大 `1.5×` 并调为明显橙色，不缩放或染色玩家本体、碰撞体、其他动画及其他技能特效；普通火形态但未引燃时仍使用原尺寸、原颜色，动画结束或状态失效后立即复原。不新增持续光环、图标或贴图。为录制 Demo，技能设为初始拥有并默认装备到空闲 `ACTIVE_2`，不进入奖励池、商店、价格与等级成长体系；内容图标允许为空。

完成：多个敌人的火层被一次性、稳定、原子地清空并正确合计，水层保留；吸收 1、5、20 层时普攻分别获得 5%、25%、100% 增伤并附着 1 层火，其他技能伤害完全不变。引燃普攻在左右朝向均能命中原范围外、`1.5×` 范围内的目标，不能命中 `1.5×` 范围外目标；非引燃普攻维持原范围。无火拒绝、状态计时、覆盖刷新、到期以及死亡/换房/重载清理均确定可复现；状态到期前已接受的普攻保留锁定倍率、火元素与扩大范围，到期后的新普攻恢复中性基础数据和原范围。窗口证据须清楚对比普通普攻与引燃普攻：只有独立气流特效扩大 `50%` 且呈明显橙色，玩家本体尺寸/颜色不变，状态结束后恢复。新 Run 中技能可直接在 `ACTIVE_2` 使用，目录校验、现有初始配装和其余技能不被破坏；相关专项与正式回归通过，且没有新增图标或粒子美术文件。
