# VFX Agent 任务书：首批技能 image2 资产

状态：ACCEPTED
负责人：VFX Agent 1.0
依赖：任务 11 已验收；概念探索可与任务 14 并行
最终依赖：任务 15 提供已验收的逻辑范围、Beam 尺寸、Tick 和生成/结束时序

## 1. 任务定位

使用 imagegen/image2 工作流为首批六技能制作可审查的图标、特效概念关键帧和可入库纹理素材。

本任务只负责表现资产及其说明，不修改战斗逻辑、碰撞范围、伤害、元素层数、能量、冷却、奖励或配装规则。

## 2. 开始前要求

1. 完整阅读 imagegen 技能说明，并遵守其内置工具优先、非破坏保存和透明度验证流程。
2. 查看当前 Player、Enemy、TestRoom 和既有投射物在实际游戏尺寸下的截图。
3. 从任务 14/15 读取锁定元素、范围、时序和 Tick 规则。
4. 先提交一页风格基准和每技能一张低成本概念稿，等待用户选择后再生产最终资产。
5. 未获得风格确认前不得批量生成最终文件。

## 3. 工具与透明度规则

- 默认使用内置 `image_gen`，不要求 `OPENAI_API_KEY`。
- 多个不同资产使用逐资产调用；不能用同一提示词的多个变体代替不同技能资产。
- 若用户明确要求 CLI/API 的 `gpt-image-2`，才使用官方 imagegen CLI 流程，并先确认本机已设置 `OPENAI_API_KEY`；不得要求用户在聊天中粘贴密钥。
- 不得静默切换到其他模型。
- gpt-image-2 不作为原生透明背景方案。半透明战斗特效优先交付：
  - 纯黑背景、用于加法混合的颜色纹理；或
  - 颜色图 + 配套灰度遮罩。
- 简单不透明图标需要透明背景时，使用平坦色键背景、官方去背脚本和 alpha 验证。
- 若烟雾、火焰、玻璃感或复杂半透明边缘无法通过色键获得合格结果，停止并报告；未经用户确认不得切换到需要原生透明的 CLI 模型路径。

## 4. 风格基准

- 目标是与当前横版地牢、猫角色和 1152×648 战斗画面协调的清晰 2D 游戏特效。
- 优先可读轮廓、有限色阶和像素/低分辨率友好形状，避免写实电影烟雾遮挡角色与敌人。
- 水、火必须同时用颜色和形状区分：
  - 水：圆润液滴、涟漪、内聚弧线。
  - 火：尖锐火舌、裂纹、向外爆发轮廓。
- 动态元素技能尽量使用可着色灰度核心/遮罩，不为每种未来元素复制整套技能逻辑。
- 不在图标或特效中生成文字、数字、UI 键帽、水印或伪 HUD。
- 表现范围不得大于任务 15 的逻辑命中范围；允许视觉余辉越界，但主体冲击边界必须可校准。

## 5. 六技能资产清单

每个技能目录位于 `assets/generated/vfx/<skill_id>/`，包含最终图、源输出、提示词记录和用途清单。

### 5.1 `element_bolt`

- 一枚无文字技能图标。
- 可着色弹体核心、短拖尾和命中闪光。
- 水/火形状辨识测试图；实际逻辑继续使用锁定元素着色。

### 5.2 `elemental_fury`

- 一枚无文字技能图标。
- 小范围到 2.0 倍半径仍可缩放的爆发核心、冲击环和消散关键帧。
- 关键帧需标注：蓄力/提交、主爆发、余辉，不改变任务 15 的一次命中窗。

### 5.3 `elemental_laser`

- 一枚无文字技能图标。
- 可平铺或拉伸的 Beam 核心、边缘噪声、起点聚能和目标命中闪光。
- 颜色图 + 遮罩优先；素材必须支持穿透多目标和每 0.5 秒 Tick 的脉冲表现。

### 5.4 `element_reclaim`

- 一枚无文字技能图标。
- 向玩家内收的弧线/粒子、目标抽离标记和成功汇聚闪光。
- 失败释放没有成功特效；满能量和无元素失败只由后续 UI 使用失败反馈。

### 5.5 `burning`

- 一枚无文字被动图标。
- 小型火层激活标记和每秒 Tick 关键帧。
- 不表现为额外元素附着，不暗示消耗火层。

### 5.6 `unending`

- 一枚无文字被动图标。
- 水层到生命恢复的液滴/涟漪关键帧。
- 不使用火焰语义，不暗示消耗水层或读取玩家当前元素。

## 6. 输出与清单

每个技能至少交付：

- `icon.png`：最终无文字图标。
- 一组清晰命名的 VFX 颜色纹理、遮罩或概念关键帧。
- `prompt.md`：最终提示词、输入参考角色、使用模式和迭代说明。
- `manifest.md`：每个文件的用途、推荐混合模式、锚点、是否可着色、目标显示尺寸和依赖的任务 15 参数。

项目绑定的最终文件必须实际复制到仓库目录，不能只留在 Codex 默认生成目录。不得覆盖已存在的同名资产；需要返修时使用版本化文件名，选定后再由协调者决定替换。

## 7. 透明度与视觉 QA

- PNG 透明素材必须验证 alpha 通道、透明角、主体覆盖率和边缘色污染。
- 颜色图 + 遮罩必须验证尺寸一致、UV 对齐和灰阶范围。
- 黑底加法素材必须检查黑底接近纯黑，无意外灰框或压缩块。
- 在 TestRoom 深色背景、角色前后层级和 100%/缩放窗口下分别截图。
- 图标缩小到目标 HUD 尺寸后仍能区分六技能，且不只依赖颜色区分水/火语义。
- 激光、元素之怒和回收必须使用任务 15 的逻辑范围覆盖图做叠加检查。
- 不把概念图误标为可直接入库资产。

## 8. 文件范围
