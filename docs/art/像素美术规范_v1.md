# 《元素地牢 4.7》像素美术规范 v1

状态：试制基线（ART PREVIEW）  
适用范围：角色、敌人、世界物件、地牢瓦片、战斗 VFX、HUD 图标  
不包含：玩法碰撞、数值、关卡逻辑与正式场景接线

## 1. 风格目标

本项目采用清晰、粗颗粒、低分辨率的横版像素美术。视觉目标不是追求高分辨率插画的细节量，而是在实际游戏尺寸下做到：

- 一眼识别对象类型与交互状态；
- 同屏对象拥有相近的像素颗粒与统一的摄影机语言；
- 高光、阴影和材质服务于轮廓，不切碎轮廓；
- 角色、敌人、世界物件和瓦片看起来属于同一个世界。

现有主角与普通敌人是当前世界美术的尺度基准。技能图标属于 UI 层，不作为世界物件像素密度的基准。

## 2. 基础像素与缩放

### 2.1 逻辑尺寸

| 类别 | 建议逻辑画布/可见尺寸 | 说明 |
|---|---:|---|
| 主角动作帧 | 80×64 | 沿用现有资产基准 |
| 普通敌人动作帧 | 100×100 | 沿用现有资产基准，主体不应撑满画布 |
| 普通宝箱 | 64×48～72×56 | 不高于主角可见高度约 1.2 倍 |
| 常规传送门 | 48×80～56×88 | 必须有稳定接地点 |
| 基础瓦片 | 32×32 | 地面、墙面、平台统一模数 |
| HUD 小图标 | 32×32 | 先在 32px 检查轮廓，再制作 64px 展示版 |
| 世界 VFX | 按碰撞/范围定 | 粒子颗粒不应细于角色最小有效像素簇 |

### 2.2 显示规则

- 世界像素资产只允许 `1× / 2× / 3× / 4×` 整数缩放。
- 禁止用 256px 高分辨率图以 `0.46`、`0.56` 等非整数比例缩小来模拟像素风。
- 世界 Sprite 使用最近邻过滤；位置、锚点与摄像机尽量落在整数像素。
- 资产必须在目标逻辑尺寸下完成最后一次手工清理；高分辨率生成图只能作为概念来源。
- 同一对象的所有状态必须共用画布、比例、锚点和基线。

## 3. 轮廓、透视与体积

### 3.1 轮廓优先级

识别顺序固定为：

1. 外轮廓；
2. 最大色块；
3. 功能部件；
4. 材质细节；
5. 装饰像素。

缩到目标尺寸后，如果第 3 级之前仍不能识别，资产不通过。装饰细节不得破坏前三层。

### 3.2 横版摄影机语言

- 角色与常规世界物件采用侧视或接近正侧视。
- 普通物件最多显示一个主面和一个窄辅助面。
- 顶面可见高度通常不超过物件总高的 20%。
- 常规物件禁止使用明显等距/isometric 透视。
- 门、祭坛、宝箱等交互物可以略正面化，但必须与地面基线一致。

### 3.3 体积层级

- 每种材质默认只使用：暗面、主面、高光面三档。
- 极小物件允许压缩为暗/明两档。
- 一个物件整体建议不超过 5 个主要明度层。
- 禁止每块木板、铆钉、倒角都建立独立高光。

## 4. 描边、光源与阴影

### 4.1 描边

- 世界物件使用 1 个逻辑像素的深色外轮廓。
- 默认描边不是纯黑：水域/中性区域用深蓝黑，火域用深棕紫，紫晶区域用深紫黑。
- 内部结构线应比外轮廓浅一级或断续处理。
- 亮色能量体可以局部破边，但不能整圈发白。

### 4.2 统一光源

- 默认光源来自左上方。
- 主高光只保留一簇，面积建议不超过主体可见面积的 10%。
- 右下侧形成统一暗面；不要在四周同时打轮廓光。
- 发光材质可有自身亮心，但仍应服从一个主要亮区。

### 4.3 接地

- 所有落地世界物件必须有底部压暗、接触阴影或明确底座。
- 接触阴影使用短、硬边、低饱和暗色，不做柔软写实投影。
- 阴影宽度一般为物件宽度的 45%～75%，高度为 2～5 个逻辑像素。
- 传送门等竖直物件至少有两个明确接地点，禁止尖角悬空。

## 5. 色彩与材质

### 5.1 全局色彩

- 背景维持低明度、低饱和，角色和交互物维持中高饱和。
- 最高亮色只用于当前交互目标、攻击命中和关键能量中心。
- 同屏不同资产的暗部色相应相互接近，避免每件物体都使用独立黑色。

### 5.2 材质表达

| 材质 | 主要表达 | 避免 |
|---|---|---|
| 木材 | 2～3 条大木纹、暖主面、窄暗缝 | 每块板独立渐变、过多细纹 |
| 金属 | 一块主色、一条窄高光、一块硬暗面 | 多层倒角、全边反光 |
| 石材 | 大块破面、少量缺口、低饱和变化 | 均匀噪点、满屏裂纹 |
| 能量 | 暗中心、主色环、少量亮心 | 多圈同亮度光带、全轮廓泛白 |
| 晶体 | 2～4 个大切面、一个主亮面 | 细碎钻石切面、玻璃写实反射 |

## 6. 交互物状态规范

所有可交互世界物件至少提供三个可读阶段：

| 阶段 | 视觉表达 |
|---|---|
| 未解锁/锁定 | 降低饱和度和亮度；能量核心收束；不抢战斗焦点 |
| 可交互 | 恢复主色；关键部件点亮；允许低幅呼吸动画 |
| 已使用 | 通过结构变化表达结果；不可只依赖 UI 文字 |

### 6.1 宝箱专项

- 普通宝箱应是紧凑、朴素的战后奖励，不使用王室或传奇宝箱复杂度。
- 锁扣是唯一主焦点；金属角件仅辅助轮廓。
- 推荐状态：关闭、弹盖中间帧、开启；正式动画建议 4～6 帧。
- 开启态只改变盖子、铰链角度与少量内部亮度，箱体不得漂移或变形。

### 6.2 传送门专项

- 外框由 4～6 个大分段构成，不堆叠小型机械零件。
- 能量核心以“暗中心 + 一圈主色 + 一小块亮心”为上限。
- 锁定态关闭或压低内圈；激活态才允许能量环呼吸。
- 外框静态、能量层动态，推荐拆层；动画建议 4～8 帧低速循环。
- 底部必须有石脚、底座或嵌地结构。

## 7. 瓦片地图规范

### 7.1 模数与分层

基础瓦片为 32×32，正式场景按以下层级组织：

1. 远景：低对比大色块，不参与碰撞；
2. 墙面：中低对比，可重复拼接；
3. 地面/平台：最高轮廓清晰度，与碰撞对应；
4. 前景遮挡：少量边缘碎石、立柱或藤蔓；
5. 装饰/发光物：稀疏放置，不参与基础平铺。

### 7.2 最小瓦片集合

首套试制至少包含：

- 墙面基础块、墙面两种变体；
- 地面中心、左端、右端；
- 平台中心、左端、右端；
- 内角与外角；
- 墙脚/地面过渡；
- 破损边、裂纹或碎石变体；
- 一种低亮度背景装饰；
- 一种可独立放置的发光晶体或壁灯。

### 7.3 平铺门禁

- 四边必须按 32px 网格无缝闭合。
- 连续铺设 6 格时不得出现明显重复节奏。
- 碰撞上沿必须与视觉平台上沿一致。
- 平台顶边至少连续 2 个逻辑像素，不能被噪点打断。
- 装饰变体不得改变碰撞轮廓。

## 8. VFX 与 UI 边界

- 世界 VFX 允许比角色更亮，但颗粒尺度不能更细。
- 单次技能最多一个主爆点；附属粒子使用次亮度。
- UI 图标可以有更高细节量，但必须在 32×32 下通过剪影检查。
- 不允许把高精度 UI 图标直接缩小后作为世界物件。
- UI 面板与世界像素层可以保留不同语言，但图标边框、色彩和动效需要明确分层，避免视觉上混作同一材质。

## 9. 资产验收清单

每项世界资产提交前必须同时检查：

- [ ] 在目标逻辑尺寸下可识别；
- [ ] 使用整数缩放；
- [ ] 像素颗粒与主角/普通敌人接近；
- [ ] 主面、暗面、高光不超过约三层；
- [ ] 只有一个主要高光区域；
- [ ] 左上光源方向一致；
- [ ] 有明确接地点；
- [ ] 轮廓在暗色、水色、火色、紫色背景上均可读；
- [ ] 交互状态不依赖文字也能区分；
- [ ] 动画各帧的画布、锚点、比例与基线一致；
- [ ] 无非整数缩放造成的新颗粒；
- [ ] 无文字、水印、背景污染或多余阴影。
