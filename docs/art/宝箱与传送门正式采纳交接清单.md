## 3. 建议 Godot 导入与显示设置

四张正式切片建议统一：

- Importer：`Texture2D`；
- 压缩：Lossless/无损，不使用有损压缩；
- Mipmaps：关闭；
- Filter：关闭；场景节点明确使用 `CanvasItem.TEXTURE_FILTER_NEAREST`；
- Repeat：Disabled；
- Fix Alpha Border：开启；
- Premultiplied Alpha：关闭；
- VRAM Texture：关闭；
- 3D/normal/roughness 检测：关闭或保持无用途默认；
- Sprite 锚点：bottom-center；两态共享完全相同的本地原点；
- 世界显示：只使用 `1×/2×/3×/4×` 整数倍，不允许 `0.46`、`0.56` 一类非整数缩放；
- 世界坐标和对象缩放应落在整数像素；不对运行图做平滑重采样。

Task53 同屏 QA 后的推荐显示基线：现有主角继续 `2×`，宝箱正式 PNG 使用 `1×`，传送门正式 PNG 使用 `1×`。这使宝箱与主角可见高度接近，传送门约为主角可见高度的 `1.55×`；仍全部是整数显示。不得沿用本文件早期的宝箱/传送门 `2×` 规划值。
