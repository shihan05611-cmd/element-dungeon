# Python 合成 VFX v1

状态：可审查资产；尚未由集成 Agent 接入正式 `presentation_scene`。

## 用户选择

- 元素爆发：采纳现有 8 帧 `burst_core`。
- 元素弹：项目已有素材，本轮不修改。
- 元素回收：从每个带有匹配元素附着的敌人生成粒子，曲线飞回主角。
- 燃烧：火附着敌人身上的循环粒子；对应被动生效时显示，每秒 Tick 播放短促火星。
- 不息：水附着敌人身上的循环粒子；对应被动生效时显示，成功触发恢复时播放水滴脉冲。
- 元素激光：先使用简洁、可平铺的水/火 Beam。

## 生成方式

- 工具：Python 3 + Pillow 12.2.0。
- 脚本：`docs/vfx/tools/synthesize_skill_vfx.py`。
- 总览脚本：`docs/vfx/tools/render_synthesis_overview.py`。
- 随机内容使用固定种子，结果可重复。
- 未调用 imagegen；原因是本轮由用户明确指定使用 Python 程序化合成。
- 所有正式 PNG 均为 RGBA 透明图；GIF 仅用于审查。

## 元素差异

当前正式元素集合为水和火：

- 水：圆润液滴、气泡、环形波纹和连续边缘。
- 火：尖锐碎焰、火星、旋转碎片和锯齿边缘。

激光和回收分别生成水/火形状版本，而非只做颜色替换。

## 逻辑基准

- 元素爆发：默认逻辑半径 96，最大缩放 2.0。
- 元素激光：默认逻辑范围 320×24，每完整 0.5 秒一个 Tick。
- 元素回收：默认查询半径 160；只有成功事务播放。
- 燃烧：固定读取火层，每满 1 秒触发一次，不消耗火层。
- 不息：普攻命中后读取水层并恢复生命，不消耗水层。

这些参数仅用于资产比例与触发建议，贴图不决定碰撞或战斗时序。
