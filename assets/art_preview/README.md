# 美术试制预览

此目录保存未接入游戏的美术母版与历史预览。宝箱、传送门 v2 保持冻结采纳；潮汐地牢瓦片与场景预览已被用户退回，只能用于追溯，禁止恢复为地图实现输入。

- `world_objects/`：宝箱与传送门候选；
- `tiles/`：地牢瓦片候选；
- `scene_preview/`：候选资产的组合氛围预览；
- `sources/`：内置 ImageGen 生成的色键源图；
- `prompts.md`：本轮最终提示规格与处理说明。
- `manifest.md`：尺寸、哈希、改进点与正式化限制。

这些文件不会被正式场景引用。地图方向等待用户亲自绘制的新构图；不得继续精确切片、创建 TileSet/TileMapLayer 或复用旧场景预览。宝箱/传送门仍按其独立交付合同处理。
