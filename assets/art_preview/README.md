# 美术试制预览

此目录保存未接入游戏的美术母版、候选与组合预览。宝箱、传送门 v2 与潮汐地牢瓦片视觉母版已经冻结采纳；场景图仍为预览。

- `world_objects/`：宝箱与传送门候选；
- `tiles/`：地牢瓦片候选；
- `scene_preview/`：候选资产的组合氛围预览；
- `sources/`：内置 ImageGen 生成的色键源图；
- `prompts.md`：本轮最终提示规格与处理说明。
- `manifest.md`：尺寸、哈希、改进点与正式化限制。

这些文件不会被正式场景引用。正式接入前仍需要目标尺寸手工像素清理、精确切片、TileSet 边界验证和游戏内尺度 QA。
